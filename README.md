load cell force recorder
---
python (idk what version) and arduino ide are required

once downloaded, run install.bat in `/install` and follow the instructions
---
to use:
1. run the `/loadcell/loadcell.ino` file and upload the code to the arduino
2. run `/loadcell/run.bat`
3. do your test with the load cell in real life
4. ctrl + c in the .bat window and exit
5. the output (named according to the time and date started) will appear in `/loadcell/output` folder
